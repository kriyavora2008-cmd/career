# Career 🚀
### Job Portal & Comprehensive Tech Interview Preparation Platform

A full-stack, responsive web application for aspiring software engineers to discover high-impact jobs and master technical interviews across Aptitude, DSA, Core Computer Science, and HR rounds.

---

## 🌟 Key Features

### 1. 💼 Tech Job Portal
- **Curated Tech Openings:** SDE 1, Frontend, Backend, Full Stack, Data Engineering, DevOps, and Internships at top companies (**Google, Microsoft, Amazon, Atlassian, Razorpay, Swiggy, Zomato, CRED**).
- **Multi-Facet Search & Filters:** Search by keyword, role, company, or skills. Filter by *Remote Only*, *Internships*, *High CTC (₹20+ LPA)*, *Freshers (0-2 Yrs)*, *Saved Bookmarks*, and *Applied Jobs*.
- **Application Flow:** Interactive job modal with candidate application submission (saved to localStorage with live status tracking).
- **Post a Job:** Form allowing recruiters or developers to post new opportunities directly to the portal.

### 2. 📚 Preparation Hub
- **🧮 Aptitude & Reasoning:**
  - Quant formulas (Percentages, Profit/Loss, Time-Speed-Distance, Work-Time, P&C, Probability).
  - Logical Reasoning tricks (Blood Relations, Syllogisms, Coding-Decoding).
  - Verbal Ability grammar rules (Subject-Verb agreement, Modifiers, Parallelism).
  - **Interactive Timed Practice Quiz** with instant score calculation, solution explanations, and test history.
- **🧩 DSA Theory & Complexity Matrix:**
  - Big-O hierarchy chart and operation costs across Arrays, Linked Lists, Stacks, Queues, Hash Tables, Trees, and Heaps.
  - Core algorithmic patterns guide (Two Pointers, Sliding Window, Monotonic Stack, Floyd's Cycle, BFS vs DFS, DP).
- **💻 Technical CS Core & System Design:**
  - High-yield notes on Operating Systems (Processes/Threads, Deadlocks, Paging), DBMS (ACID, Normalization, B+ Trees), Computer Networks (TCP 3-way handshake, OSI, DNS resolution), and System Design (Scaling, Caching, CAP).
  - Interactive accordion for top technical interview questions and answers.
- **🤝 HR & Behavioral Round:**
  - Visual **STAR Method** (Situation, Task, Action, Result) framework.
  - Model answer blueprints for top behavioral questions (*"Tell me about yourself"*, *"Handling conflict"*, *"Why our company?"*, *"Weaknesses"*).
  - Top questions to ask the interviewer.

### 3. 🧩 Dedicated Topic-Wise DSA SDE Sheet
- **14 Essential DSA Topics:** Arrays & Hashing, Two Pointers, Sliding Window, Linked List, Stack & Queue, Binary Search, Trees & BST, Heap & Priority Queue, Graphs, Dynamic Programming, Backtracking, Greedy, and Bit Manipulation.
- **30 Curated Standard Problems:** LeetCode links, difficulty badges (Easy, Medium, Hard), target company tags.
- **Solution & Multi-Language Code Modal:** Full problem statement, algorithmic intuition, time/space complexity analysis, and working code solutions in **C++, Java, Python 3, and JavaScript** with one-click copy.
- **Personal Notes & Bookmarks:** Notepad to record edge-case learnings for each problem.
- **Progress Tracking:** Interactive checkboxes with celebration confetti, completion percentage meter, and difficulty counters.
- **"Pick Random Problem"** button for daily practice.

### 4. 🎯 My Career Tracker
- Track applied jobs and current hiring status.
- Review saved job bookmarks.
- Topic-wise DSA mastery bars.
- Aptitude quiz score history.
- **Export Data:** Download all progress, notes, and applications as a JSON backup.

## 🛠️ Tech Stack
- **HTML5:** Semantic markup, accessible dialogs & components.
- **CSS3:** Custom properties (CSS variables), glassmorphism, responsive grid & flexbox, dark & light themes.
- **JavaScript (ES6+ Modules):** Reactive state management, local storage persistence, quiz engine, modal controllers.
- **Canvas Confetti:** Celebration animations on goal completion.

## 🚀 Getting Started Locally

1. Clone or download this repository:
   ```bash
   git clone https://github.com/<your-username>/career_path.git
   cd career_path
   ```

2. Open `index.html` directly in your browser, or start a local server:
   ```bash
   # Using Python
   python -m http.server 8080

   # Or using Node
   npx serve .
   ```

3. Visit `http://localhost:8080` in your browser.
